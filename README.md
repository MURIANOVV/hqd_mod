# HQD Mod — Minecraft 1.21.1 (NeoForge 21.1.266)

Полноценный мод **HQD Mod** для Minecraft 1.21.1 на базе современного API NeoForge 21.1.266.

## 🚀 Стек технологий
- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.266
- **Gradle**: 8.11
- **Java**: 21
- **Mod ID**: `hqdmod`

### 2. Механика заряда (DataComponents 1.21.1)
- Заряд хранится через `DataComponentType<Integer>` (`hqdmod:charge`).
- Начальный заряд: **100/100** (настраивается в конфиге).
- Отображение полосы заряда прямо на иконке предмета (цвет полосы соответствует вкусу).
- При каждом использовании списывается 1 заряд.
- Если заряд 0 — эффекты не выдаются, предмет не ломается, игроку выводится сообщение «HQD разряжена!».
- Кулдаун между затяжками предотвращает спам.
- Синхронизированные звуки и частицы дыма.

### 3. Жидкость для вейпа (Vape Liquid)
- Полноценная жидкость NeoForge:
  - Source: `hqdmod:vape_liquid`
  - Flowing: `hqdmod:flowing_vape_liquid`
  - Блок: `hqdmod:vape_liquid_block`
  - Ведро: `hqdmod:vape_liquid_bucket`
  - Бутылка: `hqdmod:vape_liquid_bottle`

#### Варка на варочной стойке (Brewing Stand):
- **Основа**: Бутылочка воды (Water Bottle).
- **Ингредиент**: Сахар (Sugar).
- **Результат**: Бутылка жидкости для вейпа (Vape Liquid Bottle).

---

### 4. Перезарядка HQD
Поддерживаются 3 удобных способа:
1. **В руке**: ПКМ с бутылкой Vape Liquid, держа разряженную HQD во второй руке (или наоборот).
2. **В инвентаре**: Взять бутылку Vape Liquid курсором и нажать ПКМ по HQD.
3. **На верстаке**: Бесформенный крафт (HQD + Vape Liquid Bottle) -> Заряженная HQD + стеклянная бутылочка возвращается.
- 1 бутылка восстанавливает **+5 зарядов** (до максимума 10).
- Нельзя перезарядить полную HQD (бутылка не потратится).

### 5. Сборка проекта

```bash
gradlew build
```
Готовый jar-файл мода:
`build/libs/hqdmod-1.0.0.jar`

Для запуска клиента в среде разработки:
```bash
gradlew runClient
```
